## 低保真設計語言

整份原型採用統一的灰階語言，方便評審時辨識「這裡原本是什麼」：

| 視覺元素 | 意義 |
|---|---|
| 灰色橫條（skeleton） | 原頁面的文字段落位置 |
| 交叉方框（`.ph`） | 原頁面的圖片位置 |
| 細框卡片 | 可點擊的內容區塊 |
| 實心灰鈕 | 主要行動呼籲（報名、捐款） |
| 右上角編號章 | 對應文字層級框架的 p 編號（原型實作中已隱藏） |
